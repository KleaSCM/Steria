# Steria Project Scope - Phase: Frontend Refresh & Core Stabilization

## 1. Frontend Migration (Priority High) 💅
**Goal:** Replace the current React/Vite web interface with a desktop-native **Electron + Svelte** application.
**Reasoning:** "Svelte is less shit" and we want a standalone app experience.
**Tech Stack:**
  **Frontend:**
  - **Framework:** Electron + Svelte + TypeScript
  - **Build Tool:** Vite
  - **Styling:** CSS Variables (Modern Sapphic Palette)
  - **Reasoning:** Svelte offers superior performance and a smaller bundle size compared to React, which is crucial for a desktop application that needs to stay lightweight.
  - **Previous Stack:** React (Nuked 💥)
  - **Design:** Minimalist for now. Do not over-engineer. Focus on core functionality working with the backend.
